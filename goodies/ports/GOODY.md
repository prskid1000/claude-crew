# ports

`kitbag.py port [--check | --deploy]`: Codex / Antigravity ports of the kit (`.codex/`: agents, config.toml hooks, rules/kit.rules, a manual procedure per workflow; `.agents/`: agents, hooks.json, a `run_workflow` script per workflow; GEMINI.md: Antigravity mechanics), deployed to the workspace root with absolute hook paths, `.agents/skills/<name>` links, the org rules (`.agents/rules/`, `AGENTS.override.md`: local only) and the Codex mechanics; also writes each agent's Character block from `_manifest`. `--deploy`: the workspace copies only (post-merge / post-rewrite hook, `health`). `adapters/heartbeat.ps1`: `bossy.ps1 heartbeat`, the Codex E1 timer.
Needed when: `ports.targets` = `codex` | `antigravity` | `both`, `../.codex/config.toml` exists, `../.agents/hooks.json` exists (the workspace uses the ports), or listed in kit.local.json `goodies`.
Wiring: `kitbag.py` loads `skills/bossy/kitbag_ports.py` (command `port`); `bossy.ps1 precommit` regenerates the ports, `health` (`port --deploy`, then `--check`), `prepush` and `audit scan` (PORT-DRIFT) check them when it is installed; without it they skip.

## Config (kit.local.json `ports`)
- `targets` (default `both`): which workspace-root copies every port run writes (the kit's own `.codex/`, `.agents/`, GEMINI.md are always generated).

| Value | Keeps | Removes |
|---|---|---|
| `both` | all | — |
| `codex` | AGENTS.md, AGENTS.override.md, `.codex/`, `.agents/skills/` links (Codex reads its skills there) | GEMINI.md, the rest of `.agents/` |
| `antigravity` | AGENTS.md, GEMINI.md, `.agents/` (no skill links) | AGENTS.override.md, `.codex/` |
| `none` | — | AGENTS.md, AGENTS.override.md, GEMINI.md, `.codex/`, `.agents/` |

- Removed: only kit-written files (a `generated by kitbag.py port` / `Ported note` header, the hash in `<state>/ports-deployed.json` from the last deploy, or the bytes a deploy writes now). A deselected target's folder goes whole when no authored file is left; an authored file stays and is listed. One line names what went.
- `clutter` (globs, replaces the default): never counts as authored; `name/` = a folder. Default: `CLUTTER` in `kitbag_ports.py` (OS files, editor swap / backup files, logs, caches, temp, sessions, history); empty files and folders always.
