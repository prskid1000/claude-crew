# deploys

`bossy.ps1 deploy plan | request | record | intest | merge`: the deploy batch (bossy E5: a person says `deploy <env>`; merged-not-deployed MRs per test env, `deploy.trigger` owner / ask, `deploy.minIntervalHours`), recorded deploys, promoted tasks -> inTest once live; supervise -AutoFix moves live tasks to inTest and caches the plan (DEPLOY ASK). `deploy merge -Repo <checkout> -To <target|branch> [-From] [-Check <dir>] [-Push]` merges the main line into a deploy branch in a worktree (add/add conflicts resolved to the main line) or tags it (`deploys[].tag`). `pokey.ps1 deployed -Mrs <repo>!<iid>,... [-Target] [-Detail] [-Json]`: is a merged MR live on a test env: the CI deploy job on its branch, a squash-merged deploy MR or the same content; kinds `ssh` (host checkout + installed files compared), `awsStack`, `probe` (URL / command + `probeField` / `probeRegex`), `tag`, `manual`; `laneApk`: goody android-swarm.
Needed when: `repos.*.deploys` = `*` (a repo deploys to a test env), or listed in kit.local.json `goodies`.
Wiring: `skills/bossy/adapters/deploys.ps1` and `deploy_merge.ps1`, dot-sourced by bossy.ps1 (verb `deploy`; `Get-KitSuperviseFlagsDeploys`); `skills/pokey/adapters/deployed_checks.ps1` (`Invoke-Deployed`, `Test-DeployedExtra`; pokey.ps1 loads adapters/); uses `kit.local.json` `repos[].deploys`, `productTargets`, `trackerLists`; the coordinator's E5 steps: `skills/bossy/deploys.md`. Tests: `tests.ps1` (runs `tests-*.ps1` too).
