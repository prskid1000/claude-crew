# kit-admin

kitty's tools and rules: `skills/bossy/kit-admin.md` (how to change the kit: rules, shapes, lint codes, pre-push checks, kitty steps 1-6 detail, script pitfalls; README "Extending" points to it); `kitbag.py audit setup [--fix] | config [--fill] | recover [--fix] | scan` (agents/kitty.md steps 1-4), `cost [--steps]` (start tokens per agent, workflow prompts), `release [--tag] [--publish]` (SemVer + notes), `budget raise -Reason` (the token cap x1.1), `new agent|skill|workflow|rule|event|config-key|adapter|adr`, `rename <kind> <old> <new>`, `remove <kind> <name>` (a part with its _manifest entry, Router / Events row and a test stub, in one step); the retro's lesson tools `bossy.ps1 learn -Stats | -History | -Lesson | -Bump | -Fixed | -Trim`.
Needed when: `skills/crafty/kit.local.json` exists (a configured install: the weekly audit nudge spawns kitty), or listed in kit.local.json `goodies`.
Wiring: `kitbag.py` loads `skills/bossy/kitbag_admin.py` (audit verbs setup, config, recover, scan; commands cost, release; `budget raise` through `kitbag.py budget`) and `kitbag_scaffold.py` (commands new, rename, remove), and `skills/bossy/adapters/kit_admin.ps1` (dot-sourced by bossy.ps1: `Invoke-LearnAdmin`, the weekly audit nudge `Get-KitHealthLinesAudit` in `bossy.ps1 health`); `agents/kitty.md` reads `kit-admin.md` at step 0. Tests: `tests.ps1` (runs `tests-*.ps1` too).
